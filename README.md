# Enjambre

Proyecto de simulación de enjambre con criaturas abstractas en Three.js.

## Características
- Escena 3D con iluminación básica
- Agentes abstractos con movimiento autónomo
- 8 agentes en escena
- Movimiento con rebote en límites

## Tecnologías
- Three.js
- JavaScript

## Ejecución
Usar Live Server o servidor local.
